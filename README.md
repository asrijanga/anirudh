# Anirudh Janga

A one-page site: a sunlit Pacific Northwest meadow at the edge of the woods,
built with three.js, with who I am written over it.

**Live: [asrijanga.github.io/anirudh](https://asrijanga.github.io/anirudh/)**

- `docs/STORIES.md` — how the page is planned, story by story
- `docs/RESEARCH.md` — where every fact on the page comes from

## Run it

    npm install
    npm run dev

Every push to `main` builds and deploys to GitHub Pages via
`.github/workflows/deploy.yml`.
